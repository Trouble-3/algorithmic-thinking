# 06 — Binary Search: First Feasible Value

## Goal

Suppose a predicate is false for all values below some boundary and true from that boundary onward. Find the first true value.

## What to practice

- maintaining the search invariant
- logarithmic search
- monotonic feasibility
- turning an optimization-style question into a decision question

`first_true` in `src/binary_search.c` is the reusable primitive.
