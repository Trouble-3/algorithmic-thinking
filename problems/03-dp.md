# 03 — Memoization & Dynamic Programming: Minimum Coins

## Goal

Given coin denominations and a target amount, find the minimum number of coins needed to reach that amount, or report that it is impossible.

## What to practice

- identifying overlapping subproblems
- top-down memoization
- bottom-up dynamic programming
- defining a useful subproblem

The repository includes a bottom-up implementation in `src/dp.c`. Extend it with a top-down version and compare the two.
