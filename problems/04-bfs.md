# 04 — Graphs & BFS: Shortest Unweighted Distance

## Goal

Given an unweighted directed graph and a starting vertex, compute the minimum number of edges from the start to every reachable vertex.

## What to practice

- graph modeling
- adjacency lists
- queue-based BFS
- shortest paths measured by edge count

The repository implementation uses an adjacency list and records `-1` for unreachable vertices.
