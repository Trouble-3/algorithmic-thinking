# 07 — Heaps & Segment Trees: Fast Queries

## Goal

Use the two structures in this repository for two different needs:

1. repeatedly extract the smallest value with a min-heap;
2. answer range-maximum queries with a segment tree.

## What to practice

- heap invariants
- `sift_up` / `sift_down`
- range decomposition
- logarithmic updates and queries

Extend the segment tree with a range-sum query as an optional exercise.
