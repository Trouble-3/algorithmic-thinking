# 02 — Trees & Recursion: Subtree Aggregate

## Goal

Given a binary tree whose nodes contain integers, compute:

- the height;
- the sum of all values;
- an inorder traversal.

## What to practice

- base cases
- recursive cases
- combining solutions from smaller subtrees
- tree representation with pointers

## Suggested progression

Draw the recursive calls for a tree of five nodes before writing code.

The implementation in `src/tree.c` provides a compact reference structure for experimentation.
