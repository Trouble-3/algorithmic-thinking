# Roadmap

This project mirrors the book's eight-chapter progression.

## 01 — Hash Tables

Focus:
- fast membership lookup
- hashing and buckets
- collision handling
- recognizing when repeated linear searches are the real bottleneck

Implementation:
- integer set using separate chaining

## 02 — Trees and Recursion

Focus:
- tree structure
- base case / recursive case
- solving a problem from smaller subproblems

Implementation:
- binary tree
- recursive traversal
- height

## 03 — Memoization and Dynamic Programming

Focus:
- overlapping subproblems
- memoization as top-down recursion
- dynamic programming as bottom-up iteration

Implementation:
- memoized Fibonacci
- bottom-up minimum-coin problem

## 04 — Graphs and Breadth-First Search

Focus:
- modeling relationships as graphs
- adjacency lists
- BFS and shortest paths in unweighted graphs

Implementation:
- adjacency-list graph
- BFS distance array

## 05 — Shortest Paths in Weighted Graphs

Focus:
- weighted graphs
- single-source shortest paths
- Dijkstra's algorithm

Implementation:
- weighted adjacency list
- Dijkstra using a min-heap

## 06 — Binary Search

Focus:
- logarithmic search
- monotonic feasibility
- turning an optimization question into a feasibility check

Implementation:
- exact search
- first feasible value in a monotone predicate

## 07 — Heaps and Segment Trees

Focus:
- fast minimum/maximum access
- priority queues
- range queries

Implementation:
- min-heap
- range-maximum segment tree

## 08 — Union-Find

Focus:
- maintaining equivalent sets
- representatives
- path compression

Implementation:
- disjoint-set union
- union by size + path compression
