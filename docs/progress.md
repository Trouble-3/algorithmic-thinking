## Personal learning log

For each chapter, record one observation instead of only checking the box:

- **Naive idea:** what would the straightforward solution do?
- **Bottleneck:** which operation dominates the runtime?
- **Invariant:** what must remain true after every update?
- **Optimization:** which data structure or algorithm removes the bottleneck?
- **Complexity:** expected time and space.
- **Edge case:** the smallest case that could break the implementation.

This turns the repository from a code dump into evidence of algorithmic reasoning.
