# Chapter Solutions

These are small, runnable companion solutions for the eight chapter themes. They intentionally use original problem statements and input formats rather than reproducing the book's exercises.

| Chapter | Solution | Core idea |
|---|---|---|
| 01 | duplicate-detector | hash set |
| 02 | tree-aggregate | recursion |
| 03 | min-coins | dynamic programming |
| 04 | bfs-distances | breadth-first search |
| 05 | dijkstra | weighted shortest paths |
| 06 | first-feasible | binary search on a monotone predicate |
| 07 | range-max | segment tree |
| 08 | dynamic-communities | union-find |

Build everything with CMake, then run any executable directly from `build/`.
